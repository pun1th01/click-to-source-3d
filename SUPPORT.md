# Getting help

**Start with the docs.** The [README](README.md) walks through installing and using
every feature, and most problems are covered in its
[Troubleshooting](README.md#troubleshooting) and
[Limits](README.md#limits-worth-knowing) sections.

**Have a question, or an idea you'd like to talk through?** Ask in
[Discussions](https://github.com/pun1th01/click-to-source-3d/discussions).

**Found a bug?** [Open an issue](https://github.com/pun1th01/click-to-source-3d/issues/new/choose).
The form asks for the versions you're on and how to reproduce it.

**Found a security problem?** Please don't post it publicly. See the
[security policy](SECURITY.md).

This project has one maintainer, so a reply may take a few days.
