# Contributing to Click-to-Source 3D

Thank you for your interest in contributing to Click-to-Source 3D!

## Current Status

The project is in **early development**. We are currently building the foundational architecture and are not yet accepting external contributions.

Contributions will open once the MVP architecture stabilizes. We expect this to happen after **Stage 1 (Manual Provenance Prototype)** is complete.

## How You Can Help Now

While we're not accepting code contributions yet, you can still participate:

- **Open Issues** — Share ideas, report bugs, or ask questions via [GitHub Issues](../../issues).
- **Discussions** — Join conversations about the project direction and design decisions.
- **Documentation** — Suggest improvements to existing documentation.

## When Contributions Open

Once we begin accepting contributions, the following guidelines will apply:

### Development Workflow

1. Fork the repository.
2. Create a feature branch from `main` (`git checkout -b feature/your-feature`).
3. Make your changes.
4. Ensure all tests pass.
5. Submit a pull request using the provided PR template.

### Code Standards

- Write clean, well-documented TypeScript.
- Follow the established project conventions and architecture.
- Include tests for new functionality.
- Keep pull requests focused — one feature or fix per PR.

### Commit Messages

Use clear, descriptive commit messages:

```
type(scope): brief description

Longer explanation if necessary.
```

Types: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, `build`

### Code of Conduct

All contributors are expected to follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Questions?

If you have questions about the project or want to discuss potential contributions, please open an issue.
